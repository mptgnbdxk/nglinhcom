PINKIE / NGLINHH COMMISSION WEBSITE

Cấu trúc thư mục cần có:

pinkie_commission_web/
├── index.html
├── style.css
├── script.js
├── tos.html              <- giữ file TOS của bạn, không thay
├── tos.css               <- giữ file TOS của bạn, không thay
├── Couple/
├── Full/
├── Half/
├── Head/
└── Người thật/

QUAN TRỌNG
1. Không cần đổi tên các ảnh trong các folder.
2. Đặt các folder ảnh cùng cấp với index.html.
3. Mở đúng folder pinkie_commission_web trong VS Code.
4. Right click index.html -> Open with Live Server.
5. Script.js sẽ tự đọc danh sách ảnh trong 5 folder và đưa ảnh vào gallery.

Số lượng hiển thị:
- Người thật: 1 ảnh chibi
- Head: 8 ảnh
- Half: 8 ảnh
- Full: 16 ảnh
- Couple: 9 ảnh

Nếu một folder có nhiều hơn số trên, website chỉ lấy số đầu tiên theo tên file.
Các tên file có số sẽ được sắp xếp tự nhiên (01, 02, 03... rồi 10, 11...).

Nếu giá commission hoặc link liên hệ cần đổi, sửa trực tiếp ở index.html.
